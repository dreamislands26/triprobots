# TRIPROBOTS Agents

Собственный сервис ИИ-агентов TRIPROBOTS: фронт-офис и маркетинг.

## Принципы

- агент предлагает — человек подтверждает всё, что уходит наружу от имени компании, кроме типовых ответов из базы знаний;
- персональные данные не отправляются в модель: телефоны, email и Telegram username маскируются до вызова LLM;
- критичные действия выполняются отдельными инструментами с минимальными правами;
- все действия журналируются;
- при недоступности модели заявка не теряется: сохраняется в PostgreSQL и отправляется уведомление владельцу.

## Структура

- `src/frontoffice/` — агент фронт-офиса;
- `src/marketing/` — маркетинговый агент;
- `src/shared/` — LLM-адаптер, маскирование ПДн, журнал;
- `kb/` — база знаний;
- `prompts/` — системные промпты;
- `sql/` — схема PostgreSQL.

## Быстрый запуск

```bash
cd agents
cp .env.example .env
npm install
npm run dev
```

Проверка:

```bash
curl http://localhost:8788/health
```

## Первый этап

1. Поднять PostgreSQL в РФ.
2. Заполнить `.env`.
3. Запустить сервис.
4. Подключить `/api/lead` с сайта.
5. Создать Telegram-бота фронт-офиса и Telegram-бота согласований.
6. После тестов подключить CRM и календарь.

Архитектура намеренно не привязана к одному поставщику модели: используется OpenAI-compatible API через `LLM_BASE_URL` / `LLM_MODEL`. Инструменты и бизнес-логика остаются своими.
